联系支持
如何注册和登录？

注册时填写昵称、用户名、邮箱和密码，按页面提示完成邮箱验证。登录时可使用用户名、用户 ID 或邮箱，加上密码。所有平台使用同一个账号。

手机上需要安装应用吗？有 iOS 或 macOS 版吗？

手机浏览器可以直接访问 ks.chzih.com，查看日历、管理任务和参与协作。目前提供 Windows 与 Android 客户端；iPhone、iPad 和 macOS 用户可使用网页版，暂不提供对应的原生安装包。

可以完全离线使用吗？设备间多久同步？

日历与协作等主要功能需要联网。随手记支持在当前浏览器保存本机草稿，联网后在“工具与支持 → 离线草稿”中手动上传。在线界面通常每 30 秒检查跨设备变化，也可以在同步状态中重试；不是所有操作都支持离线。

没收到提醒，应该检查什么？

先检查事项的提醒时间、系统通知权限和网络状态。Android 后台推送还需要应用注册设备，并可能受到系统省电与后台策略影响。可以在“工具与支持 → 提醒诊断”中测试通知、查看设备与发送记录。协作通知与时间提醒可以分别设置。

计划完成后怎么办？误删的内容能恢复吗？

计划可以结束或归档，保留成员和完成记录，并从日常任务、日历与提醒中收起；恢复进行中后可以继续使用。日历、日程、计划、任务节点、随手记与个人模板删除后保留 30 天，可按当前权限从回收站恢复。账号永久注销不属于回收站恢复范围。

可以导入其他日历吗？重复规则怎么处理？

可以在“工具与支持 → 日历工具”中导入和导出 ICS 文件，导入前可预览并按 UID 跳过重复项。支持普通与全天日程及部分常用重复规则，暂不支持的规则会提示。重复日程中的“工作日”指周一至周五，法定节假日与调休需要手动设置跳过日期。

共享内容和账号隐私怎么管理？

共享日历可设置可编辑或只读成员，计划按成员角色控制操作。随手记和个人模板仅自己可见。你可以管理登录设备、通知偏好，或永久删除账号与关联数据。详情见 隐私政策。
